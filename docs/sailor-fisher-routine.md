# West-facing sailor fisherman

Resident **10005** uses the existing sailor walking sheet and two west-facing fishing cels, each lasting 600 ms. The fishing sprite origin is **48270, 47955**, stored as town 0 offset **2766, 2451**. The float sits over water west of the sailor; the walking and fishing feet match pixel for pixel. Editable artwork is `art/npcs/sailor_fisher_fishing.aseprite`; `tools/create_sailor_fishing.py` reproduces it and the runtime PNG/JSON from existing assets without paid tools.

New games and saves through version 13 start already fishing. Initialization anchors to the shared advancing world clock. Every cycle lasts 43200 game seconds (15 real minutes); the sailor reaches the right-hand bed in town 0's interior-3 brick cottage exactly at hour 10, sleeps for two hours, and wakes at hour 12. Later cycles include the outbound journey. The first fishing period excludes that journey. On seeds 387 and 2026, return departure is approximately hour 9.443.

Travel time includes measured indoor/outdoor route lengths at 90 pixels per real second and all four doorway effects. Indoor movement checks the feet box. Outdoors, the existing trail router is tried first; where its nearest trail access lies across the river, a town-wide collision-checked search favors trail cells by a factor of six. No teleportation or schedule correction is used. Door transfers preserve the last walking pose. A failed route or an overlong journey logs a diagnostic and leaves the sailor stationary at home. Candidate fishing points are checked nearest-first within one tile if the requested shoreline origin is obstructed.

Resident updates own all timing, including offscreen movement, clock pauses, and hourly skips. Awake phases expose Grandma-style topic menus; sleeping says only `Zzzz...`, and doorway transfers have no TALK prompt. See `docs/sailor-dialogue-ui-cases.md` for all current text. Older resident footers retain their existing layouts and migration.
